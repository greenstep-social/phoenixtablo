PHOENIX — общее табло для телефона и Streamlabs

1. Распакуйте архив. В репозиторий greenstep-social/phoenixtablo загрузите СОДЕРЖИМОЕ папки:
   index.html           (заменить прежний)
   api/state.js         (папка api должна оказаться в корне)
   lib/match.js         (папка lib должна оказаться в корне)
   package.json
   vercel.json
   START-HERE.txt        (необязательно)
   Не загружайте ZIP вместо файлов и не помещайте всё в дополнительную вложенную папку.
   В GitHub: Add file → Upload files → перетащить файлы и папки → Commit changes.

2. Vercel → phoenixtablo → Settings → Environment Variables:
   Добавьте SCOREBOARD_ADMIN_TOKEN
   Значение: придумайте длинный пароль пульта (желательно 16+ символов).
   Выберите Production (и Preview, если используете тестовые деплои).
   Это пароль для ввода на телефоне. НЕ публикуйте его в GitHub и не заменяйте им токен базы.

3. Переменные KV_REST_API_URL и KV_REST_API_TOKEN добавляются интеграцией Upstash.
   Убедитесь, что они подключены к Production. Значения копировать в HTML не надо.
   Код также поддерживает UPSTASH_REDIS_REST_URL и UPSTASH_REDIS_REST_TOKEN.

4. Vercel → Settings → Build and Deployment:
   Framework Preset: Other
   Root Directory: корень репозитория
   Build Command: пусто (при необходимости включите Override и очистите поле)
   Output Directory: .
   Install Command: по умолчанию
   Затем Deployments → последний деплой → Redeploy. Дождитесь Ready.

5. На телефоне откройте https://phoenixtablo.vercel.app/
   Введите пароль из SCOREBOARD_ADMIN_TOKEN → Подключить пульт.
   Телефон и компьютер могут находиться в разных сетях, но оба должны иметь интернет.

6. В Streamlabs добавьте Browser Source с URL:
   https://phoenixtablo.vercel.app/?view=overlay
   Размер: ширина 1200, высота 260. Фон прозрачный, кнопок нет.
   Используйте именно ссылку Vercel, не локальный файл и не старую ссылку конвертера.

7. Проверка: +1 на телефоне → в пределах примерно 2–3 секунд меняется табло.
   Отмена восстанавливает очки и подачу. Смена сторон перемещает названия, сеты и логотип.
   Таймер считается по серверному времени: запустите его один раз в начале матча.
   Он продолжает идти при закрытии пульта и не обнуляется между сетами.
   Новая база начинает с 0:0, 0:0 по сетам, таймер 00:00.
   Старый счёт из localStorage автоматически не переносится.

ЕСЛИ ЕСТЬ ОШИБКА
- «Сервер не найден»: проверьте api/state.js в корне и дождитесь нового деплоя.
- «Не найдены переменные базы»: подключите Upstash к Production, затем Redeploy.
- «Добавьте SCOREBOARD_ADMIN_TOKEN»: добавьте переменную и выполните Redeploy.
- «Неверный пароль»: введите на телефоне то же значение, что в Vercel.
- При обрыве связи текущие данные остаются на экране; появляется предупреждение.
  «Повторить отправку» повторяет ТО ЖЕ действие без двойного начисления.
  Не нажимайте новое +1 вместо повторной отправки, пока не проверите текущий счёт.
- Старый tablo-2.html можно оставить, но он не синхронизируется. Пользуйтесь главной страницей.

РАСХОД ЛИМИТА
Каждая открытая страница запрашивает состояние примерно раз в 2 секунды.
Пульт + одно табло за 2 часа: примерно 7200 чтений плюс команды изменения.
Закрывайте страницы после трансляции. Тарифы и лимиты смотрите в своих Vercel/Upstash.

ПРОВЕРКА
Локально проверены логика и серверный обработчик с имитацией Upstash:
очки/подача, отмена, стороны/названия/логотип/сеты, таймер, проверка пароля,
защита от повторов и одновременных изменений.
Подключение к вашей реальной базе и Streamlabs проверяется после загрузки.
Дизайн взят из текущего index.html репозитория, включая его шрифты и SVG-логотипы.
